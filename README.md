# hxyfront-62001 船舶轮机值班台账

面向船舶轮机值班的浏览器本地记录系统：按班次记录主机转速、滑油压力、冷却水温、燃油读数，异常项可追加处理说明。**数据只存浏览器（localStorage），不接后台、不加运行时依赖。**

## 功能

- **班次管理**：新建 / 切换值班班次（日期 × 6 个时段），当前选择持久化，刷新后保持。
- **参数录入**：每条记录含读数时间、设备（可选可输）、主机转速 rpm、滑油压力 MPa、冷却水温 °C、燃油读数 m³；超出参考范围即时高亮（范围仅提示，异常以人工标记为准）。
- **异常处理**：可标记异常并填写描述；处理说明只能**追加**（带时间戳），提交后不可修改、不可删除，可在某次追加时勾选闭环。
- **交接冻结**：存在未闭环异常时禁止完成交接；交接后班次立即冻结——不能新增 / 改写 / 删除读数，不能清除异常，只能继续追加处理说明。
- **共用一份数据**：按设备筛选、机舱参数看板（末值 / 最低 / 均值 / 最高）、异常时间线、交接班摘要均取自同一份 localStorage 数据；切换班次、刷新页面、多标签页（storage 事件同步）后保持一致。
- 交接班摘要支持浏览器打印 / 另存 PDF。

## 冻结与交接规则（reducer 强制）

| 操作 | 值班中 | 已交接（冻结） |
| --- | --- | --- |
| 新增 / 改写 / 删除读数 | 允许 | 禁止 |
| 清除异常标记 / 闭环状态 | 允许（随读数表单） | 禁止 |
| 追加处理说明 | 允许 | 允许 |
| 完成交接 | 仅当异常全部闭环 | — |
| 修改交接备注 | 允许 | 禁止 |

## 技术栈

React 19 + Vite + TypeScript，无额外运行时依赖。

npm run dev
